# مهاباد از نگاه شما — راهنمای راه‌اندازی

## چیزی که ساخته شده
یک وب‌سایت Next.js با امکانات کامل شبکه‌ی اجتماعی محلی: ثبت‌نام (نام، نام کاربری، شماره، تاریخ تولد، ایمیل)، پروفایل با عکس/پست‌ها/فالوور، فالو کردن کاربران و محله‌ها، پیام خصوصی، بلاک/میوت، بوکمارک، گزارش تخلف، کانال گفتگوی عمومی با ری‌اکشن، اطلاعیه‌های ادمین با اعلان زنده، پنل مدیریت کامل (کاربران، آمار، کاربران فعال، بن موقت، حذف کامل کاربر، لاگ فعالیت)، و محدودیت ۲ پست در ۲۴ ساعت برای جلوگیری از اسپم.

> **نکته‌ی مهم:** این نسخه به یک متغیر محیطی جدید نیاز داره: `SUPABASE_SERVICE_ROLE_KEY`. این کلید مخفیه (نه Public) و فقط برای «حذف کامل کاربر توسط ادمین» استفاده می‌شه. از Supabase: Project Settings → API Keys → کلید `service_role`. این کلید رو به `.env.local` (برای تست محلی) و بعداً به Environment Variables توی Vercel (برای انتشار) اضافه کنید — **هرگز** با کسی به اشتراک نذارید یا توی گیت‌هاب پابلیک نذارید.

> اگه قبلاً نسخه‌ی قدیمی‌تر `schema.sql` رو اجرا کرده بودید، کافیه SECTION 3 تا SECTION 5 (که به آخر فایل اضافه شدن) رو توی SQL Editor اجرا کنید — نیازی به پاک کردن جدول‌های قبلی نیست.

## قدم ۱ — ساخت پروژه‌ی Supabase (رایگان)
1. به [supabase.com](https://supabase.com) بروید و یک حساب بسازید.
2. روی «New Project» بزنید، یک اسم و رمز عبور دیتابیس انتخاب کنید (رمز رو جایی یادداشت کنید).
3. صبر کنید تا پروژه ساخته بشه (حدود ۲ دقیقه).

## قدم ۲ — ساخت جدول‌ها
1. از منوی سمت چپ، وارد **SQL Editor** بشید.
2. یک Query جدید بسازید، کل محتوای فایل `supabase/schema.sql` رو کپی کنید و اجرا (Run) کنید.
3. این کار جدول‌های `photos`، `comments`، `likes`، `neighborhoods`، قوانین امنیتی (RLS)، و باکت ذخیره‌سازی عکس رو می‌سازه.
4. اختیاری: توی همون فایل، لیست محله‌های واقعی مهاباد رو جایگزین نمونه‌ها کنید (یا بعداً از تب Table Editor ویرایش کنید).

## قدم ۳ — گرفتن کلیدهای اتصال
1. از منوی سمت چپ بروید به **Project Settings → API**.
2. مقدار **Project URL** و **anon public key** رو کپی کنید.

## قدم ۴ — اجرای پروژه روی سیستم خودتان
```bash
# اگر Node.js نصب ندارید، اول از nodejs.org نسخه‌ی LTS رو نصب کنید
npm install
cp .env.example .env.local
```
حالا فایل `.env.local` رو باز کنید و مقادیر قدم ۳ رو جایگزین کنید:
```
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
```
سپس:
```bash
npm run dev
```
و آدرس `http://localhost:3000` رو باز کنید — سایت باید کار کنه.

## قدم ۵ — انتشار روی اینترنت (رایگان با Vercel)
1. کد رو توی یک ریپازیتوری GitHub بذارید (اگه با Git راحت نیستید بگید، راهنمایی می‌کنم).
2. وارد [vercel.com](https://vercel.com) بشید، با GitHub وارد بشید، روی **New Project** بزنید و ریپازیتوری رو انتخاب کنید.
3. توی بخش **Environment Variables**، همون دو متغیر `.env.local` رو اضافه کنید.
4. روی **Deploy** بزنید. بعد چند دقیقه یک آدرس واقعی (مثلاً `mahabad-city.vercel.app`) بهتون می‌ده.
5. بعداً می‌تونید یک دامنه‌ی دلخواه (مثل mahabadcity.ir) رو هم از تنظیمات Vercel بهش وصل کنید.

## نکات مهم
- ایمیل تایید حساب به‌صورت پیش‌فرض توسط Supabase فرستاده می‌شه؛ برای شروع کافیه، بعداً می‌تونید تنظیماتش رو در Authentication → Email سفارشی کنید.
- اگه تعداد کاربرها/عکس‌ها زیاد بشه و به سقف رایگان Supabase یا Vercel برسید، هر دو پلن پولی مقرون‌به‌صرفه دارن.
- برای مدیریت محتوای نامناسب فعلاً باید مستقیم از Table Editor توی Supabase عکس/کامنت رو پاک کنید؛ اگه بعداً بخواید یه پنل ادمین ساده هم می‌تونیم اضافه کنیم.
